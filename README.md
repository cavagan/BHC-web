# BHC-web

**BurkeHaven Counseling LLC** official website — **v0.1.1**

A multi-page static website for BurkeHaven Counseling, a family-focused counseling practice in Bethany, Oklahoma, serving the Oklahoma City metro area.

## Brand

This site follows the official BurkeHaven Counseling brand style guide (navy palette, cabin logo, script typography). See `style-guide.html` and `BurkeHaven_Style_Guide.pdf` for full details.

## Site Structure

| File | Purpose |
|------|---------|
| `index.html` | Home |
| `about.html` | About Sandra Thomas-Tyler, LPC & practice story |
| `services.html` | Therapeutic counseling & specialty services |
| `case-studies.html` | Stories of healing |
| `contact.html` | Contact form & practice information |
| `style-guide.html` | Interactive brand style guide |
| `styles.css` | Brand styles |
| `script.js` | Navigation, form validation, interactivity |
| `imagine_images/` | Logo and supporting images |
